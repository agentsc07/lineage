# Documentation index

**Read first (the submission set):**

| File | What it is |
|---|---|
| `FINAL_LOGICAL_AUDIT.md` | The flow step by step with evidence, intake routes, identity and parents, LLM and GPU status, decisions, graph |
| `FINAL_TEST_MATRIX.md` | Every registered check with its test status (generated by `scripts/gen_final_matrix.py`) |
| `CONSUMER_AND_PASSPORT_FLOW.md` | Creator passport, organisation passport, attestation, pull, load, revoke, with live command output |
| `FINAL_DEMO_RUNBOOK.md` | Clean start, click sequence, commands, what to say |
| `FINAL_BLOCKERS.md` | What was fixed, what must not be claimed, what is unresolved |
| `CLAIMS.md` | Every benchmark number traced to a file, held-out or not |

**Reference:**

| File | What it is |
|---|---|
| `../README.md` | What Lineage is, the four rules, limits |
| `startup.md` | Install, run, configuration, common problems |
| `ARTIFACT_FLOW.md`, `PASSPORTS.md` | Field-level flow and passport formats |

`../archive/` holds superseded audits, screenshots, the old demo script, Q&A and roadmap. Nothing there is needed to run the application.

## Repository layout

`lineage/` library and CLI (pipeline, checks, policy, passports, client) · `lineage_server/` FastAPI registry · `dashboard/` React UI · `gpu_worker/` GPU and reviewer worker · `mcp_gateway/` MCP tool gateway · `examples/` demo (fake hub, scenario, samples) · `scripts/` generators and checks · `tests/` · `bench/` benchmark corpora, scripts and results · `bank/` reference-model manifest for the worker · `docs/` · `archive/` (not needed to run).
