## S1 Identify

### Fingerprint every file

- **Looks for:** Files that are unreadable or malformed, and artifacts we already hold
- **How:** Computes a SHA-256 for every file and a Merkle root over them; for .safetensors also one hash per tensor. A repeated Merkle root is reported as already registered.
- **Reads:** Every file of the artifact (a shipped passport.json is evidence, not part of the artifact)
- **Needs:** nothing beyond the files
- **Applies to:** model, dataset, package, tool, agent
- **Code:** `lineage.intake.pipeline:_identify`
- **Finding codes:** `INTAKE.DIGEST.KNOWN`, `INTAKE.PASSPORT.MALFORMED`, `INTAKE.REF.NOT_FOUND`, `INTAKE.STAGE.ERROR`, `MODEL.FORMAT.MALFORMED_SAFETENSORS`, `MODEL.FORMAT.PICKLE_NOT_FETCHED`

## S2 Provenance

### Does it match its claimed origin?

- **Looks for:** A copy that differs from the repository it says it came from
- **How:** Compares the SHA-256 of every file with the hash the hub published for the claimed repository and revision. One differing file makes it a modified copy. With no claim nothing can be compared and trust stays unknown.
- **Reads:** File hashes (computed) against the hub's published file list
- **Needs:** a claimed origin (hf:org/name@rev or pypi:name==ver) and a reachable hub
- **Applies to:** model, dataset, package, tool, agent
- **Code:** `lineage.intake.inspectors:origin_check`
- **Finding codes:** `PROV.ORIGIN.HINT`, `PROV.ORIGIN.MODIFIED`, `PROV.ORIGIN.UNCLAIMED`, `PROV.ORIGIN.UNVERIFIABLE`, `PROV.ORIGIN.VERIFIED`
- **Seen firing on (real run, offline):** clean dataset → PROV.ORIGIN.UNCLAIMED; clean tiny model → PROV.ORIGIN.UNCLAIMED; dataset with a 5% trigger backdoor → PROV.ORIGIN.UNCLAIMED; malicious package (hooks, decode-exec, exfil, reviewer bait) → PROV.ORIGIN.UNCLAIMED; model with a backdoored chat template and a URL token → PROV.ORIGIN.UNCLAIMED; model with a malicious pickle → PROV.ORIGIN.UNCLAIMED; model with remote code in its config → PROV.ORIGIN.UNCLAIMED; poisoned MCP tool → PROV.ORIGIN.UNCLAIMED

### Publisher allow and block lists

- **Looks for:** A blocked publisher, a look-alike of an allowed publisher, or a publisher only the uploader vouches for
- **How:** Matches the publisher name against the policy's block patterns, measures its edit distance to every allowed publisher, and notes when the name is only declared.
- **Reads:** The publisher fact (from the hub or signed passport = trusted; from the upload form = declared) and the policy lists
- **Needs:** nothing beyond the files
- **Applies to:** model, dataset, package, tool, agent
- **Code:** `lineage.intake.inspectors:publisher_policy`
- **Finding codes:** `PROV.LOOKALIKE.PUBLISHER`, `PROV.PUBLISHER.BLOCKED`, `PROV.PUBLISHER.UNLISTED`, `PROV.PUBLISHER.UNVERIFIED`
- **Exercised by:** tests/test_facts.py

```python
@register("*", "S2")
def publisher_policy(ctx: IntakeContext) -> list[Finding]:
    """S2c. Block list and look-alike run on whatever name we have (they only add risk). The allow list is consulted only
    for a publisher backed by a trusted fact; a declared-only publisher is `PROV.PUBLISHER.UNVERIFIED`."""
    out: list[Finding] = []
    trusted = ctx.fact("publisher")
    declared = ctx.fact("publisher", trusted_only=False)
    pub = trusted.value if trusted else (declared.value if declared else None)
    repo = ctx.fact_value("source_repo", trusted_only=False)
    names = [n for n in (repo, pub, ctx.name) if n]
    for pattern in ctx.policy.publishers.block:
        if any(fnmatchcase(n.lower(), pattern.lower()) for n in names):
            out.append(make_finding("PROV.PUBLISHER.BLOCKED", f"Publisher matches block rule '{pattern}'", "high",
                                    "provenance", "S2", [Evidence(kind="field", ref="source.repo", detail=str(repo or pub))]))
            break
    if pub:
        allow = ctx.policy.publishers.allow
        near = [a for a in allow if a.lower() != pub.lower() and _levenshtein(a.lower(), pub.lower()) <= 2]
        basis = "" if trusted else " (basis: declared)"
        if near and pub not in allow:
            out.append(make_finding("PROV.LOOKALIKE.PUBLISHER", f"Publisher '{pub}' looks like allow-listed '{near[0]}'{basis}",
                                    "high", "provenance", "S2", [Evidence(kind="field", ref="source.repo", detail=f"{pub} ~ {near[0]}")]))
        elif not trusted:
            out.append(make_finding("PROV.PUBLISHER.UNVERIFIED",
                                    f"Publisher '{pub}' is only declared ({declared.source if declared else 'unknown'}); the allow list does not apply",
                                    "medium", "provenance", "S2", [Evidence(kind="field", ref="publisher", detail="basis: declared")]))
        elif allow and pub not in allow:
            out.append(make_finding("PROV.PUBLISHER.UNLISTED", f"Publisher '{pub}' is not on the allow list", "low",
                                    "provenance", "S2", [Evidence(kind="field", ref="source.repo", detail=pub)]))
    return out
```

### Is the parent admitted and not revoked?

- **Looks for:** A parent artifact that is revoked, unknown or not admitted
- **How:** Looks up each parent passport id in the registry and reports its status.
- **Reads:** Parent ids from a verified passport or from weights identified in S4
- **Needs:** nothing beyond the files
- **Applies to:** model, dataset, package, tool, agent
- **Code:** `lineage.intake.inspectors:parent_chain`
- **Finding codes:** `PROV.PARENT.NOT_ADMITTED`, `PROV.PARENT.REVOKED`, `PROV.PARENT.UNKNOWN`
- **Exercised by:** tests/test_intake_pipeline.py

```python
@register("*", "S2")
def parent_chain(ctx: IntakeContext) -> list[Finding]:
    out: list[Finding] = []
    for pid in ctx.parents:
        status = ctx.registry.artifact_status(pid)
        ev = [Evidence(kind="field", ref=pid, detail=f"status={status}")]
        if status == "revoked":
            out.append(make_finding("PROV.PARENT.REVOKED", f"Parent {pid[:19]} is revoked", "critical", "provenance", "S2", ev))
        elif status is None:
            out.append(make_finding("PROV.PARENT.UNKNOWN", f"Parent {pid[:19]} is not in the registry; chain cannot be verified",
                                    "medium", "provenance", "S2", ev))
        elif status not in ("admitted", "admitted_with_conditions"):
            out.append(make_finding("PROV.PARENT.NOT_ADMITTED", f"Parent {pid[:19]} is {status}", "high", "provenance", "S2", ev))
    return out
```

```python
@register("*", "S2")
def licence(ctx: IntakeContext) -> list[Finding]:
    """S2d. An allowed licence needs a trusted fact. A declared-only licence is `POLICY.LICENCE.UNVERIFIED` (low); a declared
    licence that is not allowed still adds risk."""
    trusted = ctx.fact("licence")
    declared = ctx.fact("licence", trusted_only=False)
```

- **Looks for:** A release that is too new, or whose age cannot be established
- **How:** Needs a release date from the hub or a signed passport; an upload-form date does not count. Without one the cooldown cannot be cleared.
- **Reads:** The released_at fact
- **Needs:** nothing beyond the files
- **Applies to:** package, model, dataset, tool
- **Code:** `lineage.intake.inspectors:release_age`

```python
@register(("package", "model", "dataset", "tool"), "S2")

    quarantines (a human can approve)."""

        return []
    f = ctx.fact("released_at")

                             [Evidence(kind="field", ref="released_at", detail="basis: declared" if declared else "none")], score=0)]
    return []
```

### A check that could not run

- **Looks for:** (not a defect in the artifact) a check whose input or service was missing
- **How:** Every check either reports or says it did not run; the policy prices each unrun check per environment.
- **Reads:** n/a
- **Needs:** nothing beyond the files
- **Applies to:** model, dataset, package, tool, agent
- **Code:** `lineage.policy.engine:apply_unrun_costs`
- **Finding codes:** `CHECK.NOT_RUN.ACQUIRE`
- **Seen firing on (real run, offline):** clean dataset → CHECK.NOT_RUN.LLM_REVIEW; clean tiny model → CHECK.NOT_RUN.BEHAVIOUR_DIFF, CHECK.NOT_RUN.PARENT_ID, CHECK.NOT_RUN.WEIGHT_BACKDOOR; dataset with a 5% trigger backdoor → CHECK.NOT_RUN.LLM_REVIEW; malicious package (hooks, decode-exec, exfil, reviewer bait) → CHECK.NOT_RUN.LLM_REVIEW, CHECK.NOT_RUN.PKG_METADATA; model with a backdoored chat template and a URL token → CHECK.NOT_RUN.BEHAVIOUR_DIFF, CHECK.NOT_RUN.PARENT_ID, CHECK.NOT_RUN.WEIGHT_BACKDOOR; model with a malicious pickle → CHECK.NOT_RUN.BEHAVIOUR_DIFF, CHECK.NOT_RUN.PARENT_ID, CHECK.NOT_RUN.WEIGHT_BACKDOOR; model with remote code in its config → CHECK.NOT_RUN.BEHAVIOUR_DIFF, CHECK.NOT_RUN.PARENT_ID, CHECK.NOT_RUN.WEIGHT_BACKDOOR; poisoned MCP tool → CHECK.NOT_RUN.LLM_REVIEW

```python
def apply_unrun_costs(findings: list[Finding], environment: str, policy: PolicyPack) -> list[Finding]:
    """Set the severity and score of every `CHECK.NOT_RUN.<name>` from the policy. Idempotent; other findings untouched."""
    out: list[Finding] = []
    for f in findings:
        if not f.id.startswith(NOT_RUN_PREFIX):
            out.append(f)
            continue
        name = f.id.removeprefix(NOT_RUN_PREFIX).split(".")[0]
        table = policy.unrun_checks.get(name) or policy.unrun_checks.get("default") or {}
        sev = table.get(environment) or (policy.unrun_checks.get("default") or {}).get(environment) or f.severity
        out.append(f.model_copy(update={"severity": sev, "score": SEVERITY_WEIGHT[sev]}))
    return out
```

- **Applies to:** tool

```python
def scan(manifest_path: Path, code_dir: Path) -> list[Finding]:
    try:
        manifest = json.loads(Path(manifest_path).read_text())
    except (OSError, json.JSONDecodeError):
        manifest = {}
    perms = declared_permissions(manifest if isinstance(manifest, dict) else {})
    caps = package_capabilities.extract(code_dir)
    out: list[Finding] = []
    for cap, (_, sev) in _RULES.items():
        refs = caps.get(cap)
        if refs and not is_declared(cap, perms):
            out.append(finding(f"TOOL.INTENT.UNDECLARED_{cap.upper()}", f"Tool code {_TITLES[cap]} but its manifest does not declare it", sev,
                               "tool", "S4", [ev("file_line", r) for r in refs[:8]]
                               + [ev("field", f"{Path(manifest_path).name}#permissions", f"declared: {perms or 'none'}")]))
    if not is_declared("env_secrets", perms):  # a tool that reads ~/.ssh, ~/.aws or .env without saying so
        cred = [h for h in package_capabilities.analyse(code_dir).hits
                if h.cap == "env_secrets" and "sensitive_path" in h.flags and "test" not in h.flags]
        if cred:
            out.append(finding("TOOL.INTENT.UNDECLARED_CREDENTIAL_READ", "Tool code names a credential location but its manifest does not declare credential access",
                               "critical", "tool", "S4", [ev("file_line", h.ref, h.snippet[:120]) for h in cred[:5]]
                               + [ev("field", f"{Path(manifest_path).name}#permissions", f"declared: {perms or 'none'}")]))
    for hook in ("startup_hook", "network_at_install", "install_exec"):
        if caps.get(hook):
            out.append(finding(f"TOOL.INTENT.{hook.upper()}", f"Tool ships {hook.replace('_', ' ')} code that a tool never needs", "critical",
                               "tool", "S4", [ev("file_line", r) for r in caps[hook][:5]]))
    for cap, (kw, _) in _RULES.items():
        if kw and any(k in p for p in perms for k in kw) and not caps.get(cap):
            declared = [p for p in perms if any(k in p for k in kw)]
            out.append(finding(f"TOOL.INTENT.UNUSED_{cap.upper()}", f"Manifest declares {declared} but the code never uses {cap}", "info",
                               "tool", "S4", [ev("field", f"{Path(manifest_path).name}#permissions", ", ".join(declared))]))
    return out
```

### Find the parent model from its weights

- **Looks for:** Which admitted model this one was fine-tuned from, and which tensors changed
- **How:** Compares every tensor with each admitted model on this host (relative L2 distance; similarity above 0.5 means related). If the base is named it also compares the base's embedding rows over HTTP range requests without downloading it (cosine above 0.90 means the same family).
- **Reads:** Safetensors weights; admitted models stored on this machine; the base model named by the hub or the uploader
- **Needs:** safetensors weights and either an admitted model on this host or a named base on the hub
- **Applies to:** model
- **Code:** `lineage.intake.inspectors:local_parent_diff`
- **Finding codes:** `MODEL.PARENT.CLAIM_MISMATCH`, `MODEL.PARENT.IDENTICAL`, `MODEL.PARENT.IDENTIFIED`, `MODEL.PARENT.NO_CLAIMED_BASE`, `MODEL.PARENT.UNIDENTIFIED`, `MODEL.WEIGHTS.CHANGED_LAYERS`
- **Seen firing on (real run, offline):** clean tiny model → MODEL.PARENT.NO_CLAIMED_BASE; model with a backdoored chat template and a URL token → MODEL.PARENT.NO_CLAIMED_BASE; model with a malicious pickle → MODEL.PARENT.NO_CLAIMED_BASE; model with remote code in its config → MODEL.PARENT.NO_CLAIMED_BASE

```python
@register("model", "S4")
def local_parent_diff(ctx: IntakeContext) -> list[Finding]:
    """CPU parent identification (Track A's fingerprint) against admitted models on local disk, then the tensors that
    changed. An identified parent is added to the artifact's parents, so the chain (and later the blast radius)
    includes it even though the model shipped no passport."""
    from lineage.diff.layers import diff_models
    from lineage.diff.parent import fingerprint_parent

    if ctx.path is None or not list(ctx.path.rglob("*.safetensors")):
        return [not_run("PARENT_ID", "no safetensors weights to fingerprint", "S4")]
    bank = ctx.registry.reference_models()
    if not bank:
        return [not_run("PARENT_ID", "no admitted model on this host to compare the weights with", "S4")]
    match = fingerprint_parent(ctx.path, {pid: path for pid, (_, path) in bank.items()})
    if match.parent is None:
        return [make_finding("MODEL.PARENT.UNIDENTIFIED", "No admitted model matches these weights", "low", "model", "S4",
                             source="statistical")]
    label, parent_path = bank[match.parent]
    changed = sorted((d for d in diff_models(parent_path, ctx.path) if d.changed), key=lambda d: -d.relative_l2)
    if not changed:
        return [make_finding("MODEL.PARENT.IDENTICAL", f"Weights are identical to admitted model {label}", "info", "model", "S4",
                             [Evidence(kind="field", ref=match.parent, detail=label)], source="statistical")]
    if match.parent not in ctx.parents:
        ctx.parents.append(match.parent)
    out = [make_finding("MODEL.PARENT.IDENTIFIED", f"Parent identified from weights: {label} (similarity {match.similarity:.3f})",
                        "info", "model", "S4", [Evidence(kind="field", ref=match.parent, detail=label)], source="statistical")]
    claimed = ctx.fact_value("base_model", trusted_only=False)
    if claimed and claimed not in (label, label.split("@")[0]):
        out.append(make_finding("MODEL.PARENT.CLAIM_MISMATCH", f"Card claims base '{claimed}' but weights match '{label}'", "medium",
                                "model", "S4", [Evidence(kind="field", ref="claimed_base", detail=f"{claimed} != {label}")],
                                source="statistical"))
    out += _template_vs_parent(ctx.path, parent_path, label)
    from lineage.inspect import tokenizer

    out += [f for f in tokenizer.scan(ctx.path, parent_path) if f.id != "MODEL.TOKENIZER.NO_BASE"]  # the parent's tokenizer is the base to diff against
    out.append(make_finding(
        "MODEL.WEIGHTS.CHANGED_LAYERS", f"{len(changed)} tensor(s) differ from parent {label}: " + ", ".join(d.tensor for d in changed[:4]) + ("…" if len(changed) > 4 else ""), "info", "model", "S4",
        [Evidence(kind="tensor", ref=d.tensor, detail="shape/dtype changed" if d.relative_l2 == float("inf")
                  else f"relative L2 {d.relative_l2:.3g}") for d in changed[:12]], source="statistical"))
    return out
```

### Dataset compared with its earlier version

- **Looks for:** Rows added, removed or relabelled since the last admitted version of the same name
- **How:** Hashes normalised rows and compares the sets; reports flipped labels, class drift and words that appear almost only in the added rows.
- **Reads:** The new dataset and the latest admitted version of the same name
- **Needs:** an earlier version with the same name
- **Applies to:** dataset
- **Code:** `lineage.inspect.dataset_diff:diff`
- **Finding codes:** `DATA.DIFF.ADDED_ROWS`, `DATA.DIFF.BALANCE_DRIFT`, `DATA.DIFF.LABELS_FLIPPED`, `DATA.DIFF.NEW_TOKENS`, `DATA.DIFF.SUMMARY`
- **Seen firing on (real run, offline):** clean dataset → DATA.DIFF.NO_BASELINE; dataset with a 5% trigger backdoor → DATA.DIFF.NO_BASELINE

```python
def diff(new_root: Path, old_root: Path) -> list[Finding]:
    new, _, _ = load_samples(Path(new_root))
    old, _, _ = load_samples(Path(old_root))
    if not new or not old:
        return []
    key = lambda s: _h(s.text)  # noqa: E731 - prompt + response for instruction data, the text otherwise
    old_by_text = {}
    for s in old:
        old_by_text.setdefault(key(s), s)
    new_keys = {key(s) for s in new}
    added = [s for s in new if key(s) not in old_by_text]
    removed = [s for s in old if key(s) not in new_keys]
    # same text, different label: compare on the text alone (labels are not part of `text` for classification rows)
    old_label = {}
    for s in old:
        if s.label is not None:
            old_label.setdefault(key(s), s.label)
    flipped = [s for s in new if s.label is not None and key(s) in old_label and old_label[key(s)] != s.label]
    out = [finding("DATA.DIFF.SUMMARY", f"Compared with the earlier version: {len(added)} row(s) added, {len(removed)} removed, {len(flipped)} label(s) flipped "
                   f"({len(new)} rows now, {len(old)} before)", "info", "data", "S4",
                   [ev("metric", "added", str(len(added))), ev("metric", "removed", str(len(removed))), ev("metric", "flipped", str(len(flipped)))])]
    if flipped:
        out.append(finding("DATA.DIFF.LABELS_FLIPPED", f"{len(flipped)} row(s) have the same text as before but a different label",
                           "high" if len(flipped) / len(new) >= 0.005 else "medium", "data", "S4",
                           [ev("file_line", s.ref, f"was {old_label[key(s)]!r}, now {s.label!r}") for s in flipped[:8]]))
    if added:
        frac = len(added) / len(new)
        out.append(finding("DATA.DIFF.ADDED_ROWS", f"{len(added)} new row(s) ({frac:.1%}) that were not in the earlier version",
                           "medium" if frac >= 0.05 else "low", "data", "S4", [ev("file_line", s.ref, s.text[:60]) for s in added[:8]]))
    # class balance drift
    if all(s.label is not None for s in new[:50]) and all(s.label is not None for s in old[:50]):
        a, b = Counter(s.label for s in old), Counter(s.label for s in new)
        tv = 0.5 * sum(abs(a[c] / len(old) - b[c] / len(new)) for c in set(a) | set(b))
        if tv > 0.1:
            out.append(finding("DATA.DIFF.BALANCE_DRIFT", f"Class balance moved by {tv:.0%} (total variation distance) since the earlier version", "medium", "data", "S4",
                               [ev("metric", "tv_distance", f"{tv:.4f}")]))
    # tokens that show up in the added rows and almost nowhere else
    if len(added) >= 3:
```

### Dependencies admitted?

- **Looks for:** Dependencies nobody has admitted
- **How:** Reads Requires-Dist, looks each name up in the registry and records the unadmitted ones as unregistered nodes in the lineage graph.
- **Reads:** Package metadata
- **Needs:** nothing beyond the files
- **Applies to:** package
- **Code:** `lineage.intake.inspectors:package_dependency_closure`
- **Finding codes:** `PKG.DEP.NONE`, `PKG.DEP.RESOLVED`, `PKG.DEP.UNREGISTERED`
- **Seen firing on (real run, offline):** malicious package (hooks, decode-exec, exfil, reviewer bait) → PKG.DEP.NONE
- **Exercised by:** tests/test_graph_monitor.py

```python
@register("package", "S4")
def package_dependency_closure(ctx: IntakeContext) -> list[Finding]:
    """S4. Resolve `requires_dist` against admitted packages. Every requirement not admitted becomes a ghost node (P6) and a `low`
    `PKG.DEP.UNREGISTERED`, so the monitor still watches it and a revocation still reaches this package through it."""
    info = ctx.metadata.get("info", ctx.metadata) if isinstance(ctx.metadata, dict) else {}
    reqs = list(info.get("requires_dist") or []) or [r for r in str(ctx.fact_value("requires", trusted_only=True) or "").split("\n") if r]
    if not reqs:
        return [make_finding("PKG.DEP.NONE", "No declared dependencies to resolve" if ctx.metadata else "No fetched dependency list to resolve",
                             "info", "provenance", "S4")]
    out: list[Finding] = []
    seen: set[str] = set()
    for r in reqs:
        name = _req_name(r)
        if not name or name.lower() in seen:
            continue
        seen.add(name.lower())
        ctx.graph_refs.append({"kind": "depends_on", "type": "package", "name": name, "ref": f"pypi:{name} (required by {ctx.name})"})
        if ctx.registry.package_status(name) not in ("admitted", "admitted_with_conditions"):
            out.append(make_finding("PKG.DEP.UNREGISTERED", f"Dependency {name} has not been admitted", "low", "provenance", "S4",
                                    [Evidence(kind="field", ref="requires_dist", detail=r[:120])]))
    return out[:30] or [make_finding("PKG.DEP.RESOLVED", f"All {len(seen)} dependencies are admitted", "info", "provenance", "S4")]
```

## S5 LLM review

### AI code review

- **Looks for:** Behaviour in the code that the stated purpose does not explain
- **How:** Sends short slices of code around everything already flagged to a Nemotron model, which acts as prosecutor (defender and judge follow if it finds something). Each claim must cite a file, line and API that really appears there; claims that do not are dropped. It can add risk, never remove it.
- **Reads:** Code slices only (about 7 lines around each flagged place, comments removed, at most 20 slices), the stated purpose, and the previous release's diff
- **Needs:** an NVIDIA API key or a reviewer worker
- **Applies to:** package, tool
- **Code:** `lineage.intake.inspectors:gpu_code_review`
- **Finding codes:** `LLM.REVIEW.NOTHING_TO_REVIEW`, `LLM.REVIEW.SKIPPED`
- **Exercised by:** tests/test_inspect_llm_review.py and tests/test_hosted_reviewer.py (stubbed model endpoint); no live model call in the suite

```python
@register(("package", "tool"), "S5")
def gpu_code_review(ctx: IntakeContext) -> list[Finding]:
    """Send the code behind every signal and every finding to the reviewer. A signal alone adds no risk, so the reviewer is
    what turns "this package can open sockets" into a grounded claim (or into nothing)."""
    from lineage.inspect import package_capabilities
    from lineage.inspect.llm_review import client

    if ctx.root is None:
        return [not_run("LLM_REVIEW", "no bytes to review", "S5")]
    analysis = package_capabilities.analyse(ctx.root)
    refs = [e.ref for f in ctx.findings if f.severity != "info" or f.id.startswith("PKG.SIGNAL.") for e in f.evidence if e.kind == "file_line"]
    slices = client.build_slices(ctx.root, analysis, refs)
    if not slices:
        return [make_finding("LLM.REVIEW.NOTHING_TO_REVIEW", "Reviewer ran: no source-to-sink flow, hook or risky capability to send", "info", "llm", "S5")]
    caps = sorted({h.cap for h in analysis.hits} | {k.kind for k in analysis.hooks})
    # the artifact's purpose comes from trusted facts first (PyPI summary, hub card), then its own description; a mismatch only adds risk
    purpose = ctx.fact_value("description") or ctx.metadata.get("summary") or (ctx.metadata.get("info") or {}).get("summary") \
        or ctx.fact_value("description", trusted_only=False) or _manifest_description(ctx) or ctx.name
    diff = client.make_diff(ctx.previous[0], ctx.root) if ctx.previous else None
    static = [f for f in ctx.findings if f.severity != "info"]
    found = client.review_to_findings(ReviewCodeRequest(purpose=purpose, capabilities=caps, slices=slices, diff=diff or None),
                                      ctx.gpu_url, root=ctx.root, static_findings=static)
    return [not_run("LLM_REVIEW", "the reviewer backend is unreachable (code review)", "S5") if f.id == "LLM.REVIEW.SKIPPED" else f
            for f in found]
```

### AI review of the model or dataset card

- **Looks for:** A card that contradicts the measurements, asks you to run extra code, or breaks organisation policy
- **How:** Sends the card text and a summary of earlier findings (not the files) to the model; claims must quote a real card line.
- **Reads:** README.md / MODEL_CARD.md / DATASET_CARD.md
- **Needs:** an NVIDIA API key or a reviewer worker
- **Applies to:** model, dataset
- **Code:** `lineage.intake.inspectors:gpu_card_review`
- **Finding codes:** `LLM.CARD`, `LLM.CARD.MISSING`, `LLM.POLICY`
- **Seen firing on (real run, offline):** clean tiny model → LLM.CARD.MISSING; model with a backdoored chat template and a URL token → LLM.CARD.MISSING; model with a malicious pickle → LLM.CARD.MISSING; model with remote code in its config → LLM.CARD.MISSING
- **Exercised by:** tests/test_intake_pipeline.py (fake worker), tests/test_hosted_reviewer.py (stubbed endpoint)

```python
@register(("model", "dataset"), "S5")
def gpu_card_review(ctx: IntakeContext) -> list[Finding]:
    if not ctx.card_text or ctx.root is None:
        return [make_finding("LLM.CARD.MISSING", "No model/dataset card to review", "low", "llm", "S5", source="deterministic")]
    measured = {"files": len(ctx.files), "claimed_base": ctx.fact_value("base_model", trusted_only=False),
                "findings": sorted({f"{f.id}:{f.severity}" for f in ctx.findings})}
    from lineage.inspect.llm_review import client as lc

    try:
        req = ReviewCardRequest(card_text=ctx.card_text, measured=measured)
        if ctx.gpu_url is None and lc.GpuClient().hosted:  # hosted NVIDIA API, no GPU worker needed
            resp = lc.review_card_hosted(req)
        else:
            resp = gpu.post("/review/card", req, ReviewResponse, ctx.gpu_url)
    except (gpu.GpuUnavailable, lc.GpuUnavailable):
        return [not_run("LLM_REVIEW", "the reviewer backend is unreachable (card review)", "S5")]
    card_file = next((n for n in CARD_NAMES if (ctx.root / n).is_file()), "card.md")
    shown = _card_slices(ctx.card_text, measured, card_file)
    out = claims_to_findings(resp, shown, "LLM.CARD", {"card.md": card_file})
    from lineage.inspect.llm_review import policy_hosted

    try:  # the organisation's policy against the card, by a hosted content-safety model
        if not policy_hosted.available():
            raise policy_hosted.PolicyCheckUnavailable("no hosted API key (the policy model otherwise needs the GPU worker)")
        out += claims_to_findings(ReviewResponse(claims=policy_hosted.check(ctx.card_text, ctx.policy), verdict="suspicious"), shown, "LLM.POLICY", {"card.md": card_file})
    except policy_hosted.PolicyCheckUnavailable as e:
        out.append(not_run("POLICY_CHECK", str(e), "S5"))
    return out
```
